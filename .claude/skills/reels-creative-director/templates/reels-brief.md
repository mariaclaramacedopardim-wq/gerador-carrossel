# Briefing de Reel

Briefing curto para alinhar a ideia antes de roteirizar. A skill preenche este modelo a partir do pedido; campos não informados recebem o padrão da skill e são marcados como *(assumido)*.

## 1. Essencial

| Campo | Resposta |
| --- | --- |
| **Tema** | Assunto em poucas palavras. |
| **Ângulo** | A afirmação, pergunta ou demonstração específica do vídeo. |
| **Depois de assistir, a pessoa vai...** | Saber ou conseguir fazer o quê. |
| **Objetivo principal** | Envios, salvamentos, comentários ou seguidores (escolher um). |
| **Território** | Ciência e pensamento crítico, ou wellness na prática. |
| **Série** (se houver) | Nome da série recorrente. |

## 2. Público

| Campo | Resposta |
| --- | --- |
| **Quem é** | Padrão: 22 a 40 anos, Brasil, interesse em saúde e desempenho, rotina corrida. |
| **O que já sabe sobre o tema** | Iniciante, intermediário ou avançado. |
| **Crença ou dúvida que o vídeo responde** | O que essa pessoa pensa hoje. |

## 3. Formato e produção

| Campo | Resposta |
| --- | --- |
| **Formato** | Talking head, talking head + B-roll, demonstração sem fala, voz em off, tutorial, experimento, green screen ou resposta a comentário. |
| **Duração-alvo** | Em segundos. |
| **Locais disponíveis** | Casa (qual cômodo), academia, rua/parque. |
| **Equipamento** | iPhone + tripé (padrão); luz extra e microfone, se houver. |
| **Tempo para gravar** | Ex.: 30 min, 1 h. |
| **Prazo de publicação** | Data. |

## 4. Conteúdo

| Campo | Resposta |
| --- | --- |
| **Mensagem central** | Uma frase. |
| **Evidência / fonte** | Estudo, diretriz ou experiência pessoal que sustenta o conteúdo, com grau de certeza. |
| **Ressalva necessária** | Para quem não se aplica, limitação do estudo, quando procurar profissional. |
| **Demonstração possível** | O que ela vai fazer na frente da câmera. |
| **Referências visuais** | Reels ou estilos de referência (opcional). |

## 5. Ganchos candidatos

1. Gancho A (fala + texto na tela + ação)
2. Gancho B
3. Gancho C

**Escolhido:** letra e justificativa em uma frase.

## 6. Restrições

- O que não pode aparecer (rosto de terceiros, marcas, lugar).
- Parceria/publi: sim ou não.
- Outras restrições.

## 7. Suposições feitas pela skill

Lista do que foi assumido por falta de informação, para a criadora confirmar ou corrigir.
