# Biblioteca de referências criativas

Contexto permanente para criar e editar vídeos, Reels, Stories, carrosséis, designs gráficos e conteúdos para redes sociais.
Antes de criar ou editar algo visual, o Claude consulta esta pasta (regra em [`CLAUDE.md`](../CLAUDE.md)).

> **Este repositório é público.** Tudo o que for colocado aqui fica visível para qualquer pessoa na internet.
> Não envie fotos privadas, rostos de pacientes, dados pessoais ou material que você não tem direito de compartilhar.

## Como organizar

1. **Coloque o arquivo na pasta certa** (veja a tabela acima). Uma referência que serve para várias coisas fica na pasta do
   seu uso principal; nas outras, cite o nome dela.
2. **Nomeie assim:** `AAAA-MM-DD_tema-curto_origem.ext`
   Exemplo: `2026-10-22_texto-amarelo-manuscrito_instagram.jpg`
   Sem espaços, acentos ou cedilha no nome do arquivo (evita erro no GitHub e no Codespace).
3. **Preencha uma ficha** no fim do `LEIA-ME.md` da mesma pasta (modelo abaixo). Uma referência sem ficha vale pouco:
   o Claude não sabe o que você quer copiar dela.
4. **Registre na tabela "Referências cadastradas"** no fim deste arquivo (uma linha por referência).

### O que pode e o que não pode entrar no repositório

| Tipo | Entra no GitHub? | Como fazer |
| --- | --- | --- |
| Imagens JPG, PNG, WebP (até ~2 MB cada) | Sim | Envie o arquivo direto na pasta |
| GIF curto (até ~5 MB) | Sim, com moderação | Útil para mostrar um movimento ou transição |
| Vídeos (`.mp4`, `.mov` etc.) | **Não** (bloqueados pelo `.gitignore`) | Guarde o **link** + 1 a 3 prints dos momentos que importam |
| Áudios (`.mp3`, `.wav`, `.m4a` etc.) | **Não** (bloqueados pelo `.gitignore`) | Guarde o **link** + nome da música/artista + descrição |

## Modelo de ficha

Copie e cole no fim do `LEIA-ME.md` da pasta. Preencha só o que importa e marque com **[REPRODUZIR]** o que você quer
copiar e com **[IGNORAR]** o que não interessa nessa referência.

```markdown
### <nome-do-arquivo-ou-titulo>
- **Arquivo / link:**
- **Origem / autor(a):**
- **Por que salvei:** (uma frase)
- **Usar em:** Reels / Stories / carrossel / capa / post / outro

| Aspecto | O que observar | Marcação |
| --- | --- | --- |
| Estética geral |  | [REPRODUZIR] / [IGNORAR] |
| Enquadramento |  |  |
| Iluminação |  |  |
| Cores |  |  |
| Tipografia |  |  |
| Ritmo |  |  |
| Cortes |  |  |
| Transições |  |  |
| Legendas / textos na tela |  |  |
| Áudio |  |  |
| Composição |  |  |

- **Não copiar:** (o que nessa referência NÃO combina com você)
```

### O que significa cada aspecto

- **Estética geral:** a sensação do conjunto (ex.: minimalista, editorial, caseiro, cinematográfico).
- **Enquadramento:** distância e ângulo da câmera (plano aberto, médio, close, detalhe; de cima, de frente, de lado).
- **Iluminação:** luz natural ou artificial, dura ou suave, quente ou fria, contraste.
- **Cores:** paleta dominante, saturação, tratamento de cor (filtro, LUT).
- **Tipografia:** fonte, tamanho, peso, caixa alta/baixa, cor, contorno ou sombra, posição na tela.
- **Ritmo:** duração média de cada plano, velocidade geral, pausas.
- **Cortes:** seco, no tempo da música, *jump cut*, *match cut*.
- **Transições:** nenhuma, dissolver, zoom, deslize, fade para preto.
- **Legendas / textos na tela:** como entram e saem, quantas palavras por tela, estilo.
- **Áudio:** música, narração, som ambiente, efeitos, volumes.
- **Composição:** onde ficam pessoa, objetos e texto no quadro; espaço vazio; simetria; área segura.

   antes de seguir.
